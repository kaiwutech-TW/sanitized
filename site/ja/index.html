Mac のクリーンアップと保護 · 無料・オープンソース

あなたの Mac を
クリーンで安全、
そして軽快に。

Sanitized は Rust で作られたネイティブの Mac アプリです。ジャンク削除、マルウェアスキャン、メンテナンス、ディスク分析をすべてお使いの Mac 上で行います。削除したものはまずゴミ箱か隔離領域に移されるので、いつでも復元できます。

機能

Mac のお手入れを、ひとつのアプリで。

毎日の状態チェックから、容量を占めているフォルダ、潜んでいるマルウェア、プロジェクト内の古いパッケージの発見まで。

クイックチェック

ワンクリックで Mac 全体をチェック。

どこから始めればいいかわからなくても大丈夫。クイックチェックがクリーンアップ、セキュリティ、パフォーマンス、大きなファイルのチェックを順番に実行し、結果をひとつのリストにまとめます。どれを処理するかはあなたが決めます。

  • 安全に削除できるシステムジャンクを検出
  • マルウェアと不審な自動起動項目をスキャン
  • 壊れたバックグラウンド項目と必要なメンテナンスを確認
セキュリティ保護

Apple 自身のルールで Mac のマルウェアを検出。

macOS に内蔵された XProtect の YARA ルールを直接読み込み、公開されているマルウェアデータベースも併用します。スキャン結果にはそれぞれ検出したソースが表示されます。

  • クイック、バランス、ディープの 3 つのスキャンモード
  • 起動項目、アプリケーション、ダウンロードフォルダをリアルタイム監視
  • 不審なファイルは隔離領域に移され、復元も可能
ディスクマップ

容量はどこに消えた？ 1 階層ずつたどって確認。

6 つのフォルダを並列で計算し、スキャン中は残り時間の目安を表示します。サイズは実際に使用しているディスクブロックで計算するため、du の結果と一致します。

  • ハードリンクは 1 回だけ数えるので、Docker イメージを過大に見積もりません
  • 外付けディスクやマウントしたディスクを誤って数えません
  • フォルダをクリックして掘り下げたり、ゴミ箱に入れたり
脆弱性チェック

開発者向け：プロジェクトのパッケージに既知の脆弱性はある？

フォルダを選ぶと、Sanitized がその中のすべてのプロジェクトの依存パッケージを見つけ、OSV.dev で既知の CVE を照会し、どのバージョンにアップグレードすれば修正できるかを教えてくれます。

  • npm、Cargo、PyPI、Go など主要なエコシステムに対応
  • すべての脆弱性を修正できる最小のバージョンを提案
  • node_modules、.git、build などのフォルダは自動でスキップ
すべてのモジュール

11 のモジュールが、それぞれの役割を担当。

STATUS

Mac の状態

ヘルススコア、メモリプレッシャー、ディスク、CPU、ネットワーク。メニューバーのウィジェットも。

CHECKUP

クイックチェック

クリーンアップ、セキュリティ、パフォーマンス、大きなファイルのチェックを一度に実行。

CLEANUP

ジャンク削除

キャッシュ、ログファイル、壊れた環境設定、Xcode の残りファイル、npm／Cargo などの開発用キャッシュ。

PROTECTION

セキュリティ保護

マルウェアスキャン、リアルタイム監視、隔離領域、ブラウザ機能拡張とアプリのアクセス権のチェック。

PERFORMANCE

パフォーマンス

DNS のリフレッシュ、キャッシュの再構築、データベースの整理などのメンテナンスと、ログイン項目・バックグラウンド項目の管理。

APPLICATIONS

アプリケーション

アプリを設定やキャッシュごと完全にアンインストールし、削除済みアプリの残りファイルも見つけます。

CLUTTER

不要ファイル整理

大きなファイルと、内容がまったく同じ重複ファイルを検出。

DISK MAP

ディスクマップ

各フォルダのサイズを可視化。階層ごとに掘り下げられ、所要時間の目安も表示。

CLOUD

クラウドファイル

この Mac にダウンロード済みの大きなクラウドファイルを見つけ、クラウド上のファイルは残したまま容量を空けます。

DOCKER

Docker クリーンアップ

Docker のディスク使用量を 3 段階で安全にクリーンアップ。docker コマンドだけを使い、ボリュームは決して削除しません。

CVE

脆弱性チェック

プロジェクトの依存パッケージをスキャンし、OSV.dev で既知の CVE を照会して、アップグレード先を提案。

MENU BAR

メニューバーウィジェット

ウインドウを開かなくても、メモリプレッシャー、ヘルススコア、保護の状態を確認できます。

安全の原則

クリーンアップツールで一番大切なのは、消してはいけないものを消さないこと。

Sanitized の削除操作は、すべて次のルールに従います。

01

削除はすべて元に戻せる

ファイルはゴミ箱へ、不審なファイルは隔離領域へ移します。確認なしに完全に削除することはありません。

02

触れてはいけないファイルには触れない

仮想マシンのディスクや Docker のデータファイルは保護され、削除ボタンはありません。Docker クリーンアップがボリュームに触れることはありません。

03

データはあなたの Mac の中に

アカウント不要、トラッキングなし、分析なし。ネットワークに接続するのは、1 日 1 回の Sanitized のアップデート確認（設定でオフにできます）、脆弱性チェックの実行、abuse.ch のキーを入力したとき、ほかのアプリのアップデートを確認するときだけです。

04

ソースコード公開、Apple 公証済み

GPL-3.0 のオープンソースなので、プログラムが何をしているか誰でも確認できます。インストーラは Developer ID で署名され、Apple の公証を受けています。

定義ソース

公開された、信頼できるデータから。

スキャン結果にはすべてソースが明記されているので、自分で確かめられます。

内蔵 · 自動アップデート

Apple XProtect

macOS に内蔵され、Apple が継続的にアップデートしているマルウェアの YARA ルール。お使いの Mac から直接読み込みます。

オプション · 毎日アップデート

MalwareBazaar

スイスの非営利団体 abuse.ch が公開しているサンプルデータベース。無料のキーを入力すると、最新の Mac マルウェアのフィンガープリントを毎日ダウンロードします。

内蔵

Objective-See

Mac のマルウェアを専門に研究する非営利団体。公開されている分析をもとに、各ファミリーのインストール場所のルールをまとめています。

インストール

「アプリケーション」にドラッグするだけ。

DMG をダウンロード

GitHub Releases から最新の Sanitized-arm64.dmg をダウンロードします。

アプリケーションにドラッグ

DMG を開いて Sanitized を「アプリケーション」フォルダにドラッグし、そのまま開きます。

フルディスクアクセスを許可

「システム設定 → プライバシーとセキュリティ → フルディスクアクセス」で Sanitized をオンにすると、すべての場所をスキャンできます。

必要環境：Apple シリコン（M シリーズチップ）搭載の Mac、macOS 11 以降。自分でビルドするなら cargo run --release

Mac を大掃除しよう。
