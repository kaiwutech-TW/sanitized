Sanitized is a native Mac app built in Rust. Junk cleanup, malware scanning, maintenance and disk analysis all run on your own computer. Anything it removes goes to the Trash or Quarantine first, so you can always restore it.

Features

One app for everything your Mac needs.

From a daily status check to tracking down the folders that eat your space, hidden malware and outdated packages in your projects.

Quick Checkup

One click checks your whole Mac.

Not sure where to start? Quick Checkup runs the cleanup, security, performance and large-file checks in turn, then puts the results in one list so you can decide what to deal with.

  • Finds system junk that is safe to remove
  • Scans for malware and suspicious launch items
  • Checks for broken background items and due maintenance
Protection

Catch Mac malware with Apple's own rules.

Sanitized reads the YARA rules of XProtect, which is built into macOS, and adds public malware databases. Every result shows which source found it.

  • Quick, Balanced and Deep scan modes
  • Real-time monitoring of launch items, Applications and Downloads
  • Suspicious files go to Quarantine and can be restored
Disk Map

Where did the space go? Click down, one level at a time.

Six folders are measured in parallel, with an estimate of the time left while it scans. Sizes count the disk blocks actually used, so they match du.

  • Hard links count once, so Docker images aren't overstated
  • External and mounted disks aren't counted by mistake
  • Click a folder to go deeper, or move it to the Trash
Vulnerability Check

For developers: do your project's packages have known vulnerabilities?

Pick a folder and Sanitized finds the dependencies of every project inside, looks up known CVEs on OSV.dev and tells you which version to upgrade to for a fix.

  • Supports npm, Cargo, PyPI, Go and other common ecosystems
  • Suggests the smallest upgrade that fixes every vulnerability
  • Skips node_modules, .git, build and similar folders
All modules

Eleven modules, each with one job.

STATUS

Mac Status

Health score, memory pressure, disk, CPU and network, plus a menu bar widget.

CHECKUP

Quick Checkup

Runs the cleanup, security, performance and large-file checks in one go.

CLEANUP

Junk Cleanup

Caches, logs, broken preferences, Xcode leftovers and developer caches such as npm and Cargo.

PROTECTION

Protection

Malware scanning, real-time monitoring, Quarantine, and checks of browser extensions and app permissions.

PERFORMANCE

Performance

Maintenance tasks such as flushing DNS, rebuilding caches and tidying databases, plus login and background item management.

APPLICATIONS

Applications

Uninstalls apps along with their settings and caches, and finds leftover files from apps already deleted.

CLUTTER

Clutter

Finds large files and duplicates with identical content.

DISK MAP

Disk Map

Shows the size of every folder, level by level, with a time estimate.

CLOUD

Cloud Files

Finds large cloud files downloaded to this Mac and frees the space without deleting the copy in the cloud.

DOCKER

Docker Cleanup

Safely trims Docker's disk use in three levels, using only docker commands and never removing volumes.

CVE

Vulnerability Check

Scans project dependencies, looks up known CVEs on OSV.dev and suggests upgrade versions.

MENU BAR

Menu bar widget

See memory pressure, health score and protection status without opening the window.

Safety

The most important thing for a cleaner is not deleting the wrong thing.

Every deletion in Sanitized follows these rules.

01

Every deletion can be undone

Files go to the Trash and suspicious files go to Quarantine. Nothing is deleted for good without asking you first.

02

Hands off what shouldn't be touched

Virtual machine disks and Docker's data files are protected and have no delete button. Docker Cleanup never touches volumes.

03

Your data stays on your Mac

No account, no tracking, no analytics. It only goes online to check for a new version of Sanitized once a day (you can turn this off in Settings), to run a vulnerability check, when you enter an abuse.ch key, or to check other apps for updates.

04

Open source, notarized by Apple

Released under GPL-3.0, so anyone can check what the code does. The installer is signed with a Developer ID and notarized by Apple.

Signature sources

From public, trusted data.

Every scan result names its source, so you can check it yourself.

Built in · Updated automatically

Apple XProtect

Malware YARA rules built into macOS and kept up to date by Apple, read straight from your Mac.

Optional · Updated daily

MalwareBazaar

The public sample database of abuse.ch, a Swiss non-profit. Enter a free key and Sanitized downloads the latest Mac malware fingerprints every day.

Built in

Objective-See

A non-profit dedicated to Mac malware research. Its public analyses are the basis for rules on where each malware family installs itself.

Install

Drag it to Applications, and you're done.

Download the DMG

Get the latest Sanitized-arm64.dmg from GitHub Releases.

Drag to Applications

Open the DMG, drag Sanitized to the Applications folder, then open it.

Grant Full Disk Access

Turn on Sanitized in System Settings → Privacy & Security → Full Disk Access so scans can see every location.

Requires a Mac with Apple silicon (M-series chip) and macOS 11 or later. Want to build it yourself? cargo run --release
